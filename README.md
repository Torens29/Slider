# Slider

**Слайдер изображений на чистом JavaScript**  
Компактный, настраиваемый слайдер для веб-страниц, реализованный без фреймворков.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)

## О проекте
Готовый компонент слайдера для отображения изображений.  
Функционал:
- Переключение изображений по стрелкам/точкам.
- Адаптивная вёрстка.
- Плавные CSS-переходы.
- Возможность добавления неограниченного количества слайдов.

## Технологии
- **JavaScript (ES6+)** — логика переключения слайдов.
- **CSS3** — стилизация, анимации, позиционирование.
- **HTML5** — структура контейнеров и элементов управления.

## Структура проекта
```
Slider/
```
